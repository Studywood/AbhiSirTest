# Abhi Sir Classes
1. Push this folder to GitHub and enable Pages (Settings > Pages > main / root).
2. Log in as admin, add content, open Publish, download content.zip.
3. Replace the `content/` folder in the repo with the unzipped one and commit.
Students read only from `content/`. Admin credentials exist only as a salted hash in js/auth.js.
Limits: GitHub Pages sites should stay under 1 GB; single files under 100 MB.
